## The problem

I wanted to build a simple embedded system that could measure the distance to an object in real time and display the result directly on the hardware.

The challenge was turning the HC-SR04's ultrasonic echo into an accurate distance measurement using an 8051 microcontroller and its timer.

<MarginNote>margin note: a small project, but a good exercise in understanding how hardware timing becomes something you can actually measure.</MarginNote>

## Key decisions

- **Timer-based measurement:** used the 8051's Timer0 to measure the echo duration from the HC-SR04.
- **Direct LCD output:** displayed the calculated distance on a 16x2 LCD so the result could be read directly from the hardware.

<WhatBroke>
  The key challenge was getting the timing right. The HC-SR04 measures distance through the time taken for the ultrasonic pulse to return, so the microcontroller has to accurately capture the echo duration.

  The measured time is converted using:

  **Distance (cm) = Time (µs) / 58**

  **Lesson:** embedded systems often come down to understanding timing at the hardware level.
</WhatBroke>
