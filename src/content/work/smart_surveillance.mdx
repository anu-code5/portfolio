## The problem

Traditional surveillance systems can generate large amounts of video without making the information easy to monitor or act on.

I wanted to build a single dashboard that could combine live camera monitoring with AI-powered detection, incident management, and analytics — turning raw surveillance footage into actionable security information.

The goal: monitor a camera feed, detect people and objects in real time, record incidents, and give users a clear overview of security activity from one interface.

<MarginNote>margin note: the idea was to move surveillance from passive video watching toward active, AI-assisted monitoring.</MarginNote>

## The architecture

The system is split into three services:

- **Frontend:** React + Tailwind CSS, with React Webcam, Axios and Recharts
- **Backend:** Node.js + Express.js with JWT authentication and Multer
- **AI service:** Flask + YOLOv8 + OpenCV + Ultralytics
- **Database:** MongoDB Atlas with Mongoose

The frontend is deployed on Vercel, while the backend and AI service run on Render.

<WhatBroke>
  The biggest practical constraint was inference and hosting performance. On free-tier cloud deployments, AI inference latency can become noticeable, and continuous monitoring depends heavily on available compute resources.

  Detection quality also depends on the quality and lighting of the input footage.

  **Lesson:** an AI pipeline can work correctly in isolation but still feel slow when the model, API, database and frontend all have to work together in real time.
</WhatBroke>
