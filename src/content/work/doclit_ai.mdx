## The problem

Reading long PDFs often means repeatedly searching through pages to find specific information. I wanted to build a system where a user could upload a document and simply ask questions about it in natural language.

Goal: upload a PDF, understand its contents, retrieve the relevant sections, and generate a context-aware answer.

<MarginNote>margin note: the interesting part wasn't making a chatbot. It was making sure the chatbot had the right document context.</MarginNote>

## Key decisions

- **Semantic search over keyword-only search:** questions don't always use the same words as the source document, so embeddings help retrieve conceptually relevant passages.
- **RAG instead of sending the whole document to the model:** retrieve only the relevant context before generating an answer.

<WhatBroke>
  The first challenge was retrieval. A language model can generate a convincing answer even when the retrieved context isn't relevant. The system therefore needs to focus on the quality of document chunking, embeddings and retrieval before generation.

  **Lesson:** in a RAG system, better answers start with better retrieval.
</WhatBroke>
